# Ziff docs

Planning and progress tracking for [Ziff](../) — a local Git diff viewer focused on review workflows.

## Documents

| Doc | Purpose |
| --- | --- |
| [ROADMAP.md](./ROADMAP.md) | Feature list, status, acceptance criteria, and implementation notes |

## How to use this

1. **Pick a feature** in `ROADMAP.md` and move its status when work starts or ships.
2. **Add notes** under a feature when you learn something (API limits, UX decisions, blockers).
3. **Split work** into checkboxes inside each feature — check them off as you go.
4. **Link PRs/issues** inline when they exist (e.g. `PR #12`).

## Status legend

| Status | Meaning |
| --- | --- |
| `done` | Shipped and usable |
| `partial` | Some of the feature works; gaps remain |
| `in-progress` | Actively being built |
| `planned` | Scoped but not started |
| `blocked` | Waiting on a dependency or decision |

## Current focus

Core diff and review loop — see [Core features](./ROADMAP.md#core-features) in the roadmap.
